# I-Cabs

Guruvayur Taxi & Kerala Travel Services.

## Project

A fast, mobile-first informational website for I-Cabs.

## Technology

- HTML
- CSS
- JavaScript

## Purpose

The website will showcase I-Cabs taxi, temple darshan, sightseeing,
airport transfer, railway transfer and outstation travel services.

The primary customer journey is:

Visitor → Understand Services → Trust I-Cabs → WhatsApp / Call
